# Security policy

DialAgent is experimental and currently intended for private lab networks.
Do not expose its SIP, RTP, HTTP action, or Push XML paths to the public
Internet.

Please report vulnerabilities privately through GitHub Security Advisories
after the repository is published. Do not include real call audio, credentials,
cookies, device certificates, or corporate network details in an issue.

The project does not claim confidentiality or peer authentication for direct
SIP/RTP in v0.1. Automatic answer is therefore suitable only for an explicitly
bounded demo on a trusted or isolated network.
